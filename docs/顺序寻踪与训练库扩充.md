# 顺序寻踪 1.1 与训练库扩充

## 刺激与规则
4×4 / 5×5；数字 1…N 或字母 A…；N 为 2 至方格容量的整数。字符各出现一次，与空格一起随机分配。先完整显示布局，用户主动开始作答；空格始终不可点击。
可见搜索保留字符；隐藏回忆遮住所有字符（无读屏标签泄漏），正确或错误均不揭晓字符。按序找到当前目标后推进；误点保留当前目标。每目标 60 秒，超时中断，不能跳过目标获得完成记录。建议隐藏回忆从 4–6 个字符起步；这只是产品默认建议，不是经过验证的剂量。

## 数据与评分
服务端冻结 searchConfig(gridSize, symbols, count, visibility)，版本 1.1；观察时间 observationMs 独立保存。逐目标记录 index、onsetMs、response（实际点击字符序列）、rtMs；错误也保留。正确率=无误找到的目标数/已处理目标数。完成记录必须找齐全部目标。中位时间仅统计无误目标；总作答时间为各目标时间之和，不包含观察及界面过渡。errorClicks 为非当前目标点击次数。不生成智力或注意力总分。
观察、作答阶段切走/结束均保存中断记录；中断不进入趋势。对比只允许任务、训练模式、设备、协议版本及全部配置一致，默认显示最近有效记录对应的条件；旧版 1.0 保留，不能混合。隐藏回忆还应结合观察时长解释成绩，自定观察时间不足以判断记忆能力提升。

## 丰富度与优先级
当前四项：工作记忆更新 n-back、反应抑制 Go/No-Go、序列空间记忆 Corsi、视觉搜索/位置回忆顺序寻踪。变体不当成新增能力维度。
1. 下一批：任务切换（线索、切换/重复试次平衡，分别统计正确率和切换成本）、Stroop（匹配/冲突条件平衡，统计条件差异）。先确定刺激规则及数据协议，再开发。
2. 随后：CPT（持续注意，按时间段分析遗漏、误报、反应波动）、数字正背/倒背（分开记录方向和跨度）。
3. 策略层：组块与位置记忆法教程、清单练习、真实场景应用复盘。完成课程和任务进步分开记录。
4. 后续再评估复杂广度、符号匹配及双任务，避免首版内容过多但计时与统计不可靠。

上架门槛：每项必须有规则示例、练习轮、参数边界、刺激平衡、明确的指标、逐试次数据、质量标记与同条件比较。训练任务分数不等同日常能力或临床效果。
