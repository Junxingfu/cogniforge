# CogniForge 产品设计 v0.3 · To C

日期：2026-10-27。本文替代原教练带练方案。面向普通成年人的自主训练、数据记录与复盘，不包含教练或学员管理。

> 首版任务详细规格与当前/下一协议边界见 [首版任务规格](首版任务规格.md)。本轮先细化规则，再优化导航、参数选择和反馈；不改变已有成绩口径。

## 产品目标

选择目标 → 理解规则 → 练习 → 查看表现 → 记录反思 → 调整后续安排。任务表现、固定条件复测、真实生活自述分开，不生成脑龄、智商、六维能力总分或疗效结论。

## 训练内容与合理性

| 内容 | 目的 | 主要指标 | 当前状态 |

训练任务涉及多种认知过程，不能将单任务分数等同于独立能力。近迁移与远迁移依赖研究对象和范式，不统一宣称“提高智力”。参见工作记忆训练综述：https://pmc.ncbi.nlm.nih.gov/articles/PMC11595675/ 和 https://pmc.ncbi.nlm.nih.gov/articles/PMC4968033/ 。这些文献不为全部任务或产品阈值背书。

## 使用方式

- 规则练习：先阅读规则，熟悉按键和响应窗口，单独存储。
- 正式训练：选择任务与档位，执行固定条件练习。
- 固定复测：用户主动选择固定档位，新刺激序列，不自动升级。
- 每日编排（后续）：建议短时组合、轮换任务，初始以10–15分钟每周3次为运营假设，待试点验证。

第一版保留自主选择，避免把未经验证的推荐引擎包装成个性化处方。

## 训练规则 v1.0

n-back：30+N项，前N项不计分；评分项9个目标；非目标排除意外N步重复。刺激在响应窗口内可见，响应窗口2500ms，项间准备500ms。

Go/No-Go：40项，30个Go和10个No-Go随机打乱；每试次只接受一次空格响应，忽略自动重复按键。窗口1000/850/700ms，试次起始间隔固定1500ms。

空间路径：随机选取3/4/5个不重复位置，依次亮起550ms、间隔200ms，呈现后15秒内按序重现，共5轮。部分输入和超时保留为错误响应。

舒尔特：4×4布局，按照1–16点击；错误点击不推进目标，错误点击序列随该数字的试次一起保存；每个数字60秒超时，超时记错误并进入下一数字。该超时行为与传统自由完成版本不同，后续总耗时分析必须带规则版本。

所有任务中断后均需新建会话、新序列，不继续旧序列取得可比成绩。明显计时延迟标记质量问题；浏览器不具备实验室级呈现精度。

## 自适应规划

当前固定档位。后续按任务独立配置、至少跨两个有效区块判断，区块结束后一次调整一个主要参数；不让“全不按键”或“全按键”触发升级。规则、阈值、判定理由保存版本。用户可以锁定难度。未完成和质量异常记录不参与升降级。

## 训练数据与复盘

记录四层信息：
1. 会话：任务、模式、档位、创建时间、设备、完成状态。
2. 配置：版本、窗口、实际刺激顺序与预期响应。
3. 试次：序号、相对呈现时间、实际响应（包括无响应）、反应时。
4. 结果与反思：服务端评分、有效性、质量原因、自由文本复盘。

首版每个会话就是一个区块；后续增加多任务课程实体。服务端不接受客户端总分，按配置和事件重新评分。首次提交结果后不能改写试次，备注可单独修改。

结果同时展示准确率与速度。命中率/虚报率无适用分母时显示“—”。仅正确响应进入中位反应时。趋势按任务、档位、模式和设备分开，剔除中断；目前全工程统一任务版本1.0，版本升级时需增加版本筛选，不能直接混合历史数据。

用户复盘提示：是否受打扰？是否过于着急？采取了什么策略？是否尝试在生活中应用？自述不作为客观能力结论。
