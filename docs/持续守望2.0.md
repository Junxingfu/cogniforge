# 持续守望 2.0
默认线索守望、90秒、入门档；基础守望仍可选。规则练习实际固定30秒，不进入正式趋势，显示逐项反馈；训练/复测无答案反馈。

配置：variant=BASIC/CUED，durationSeconds=90/180。规则练习由服务端覆盖为30。档位1/2/3的刺激及响应窗口为1000/800/700ms，空白间隔500/400/300ms。响应仅在刺激窗口有效，第一响应有效，长按忽略。第一项前也有空白间隔，整轮名义时长恰为所选时长；渲染开销可能略增实际时长，明显延迟标记中断。

基础：对X按键。线索：仅紧邻A之后的X按键。刺激生成采用随机打乱的AX目标片段、BX干扰片段、AB线索落空片段及无A/X的单字符填充；每轮目标数量round(试次数×15%)，BX与AB数量各round(试次数×7%/10%/13%)，基础玩法以单X取代AX，并用BC替代BX（目标仍保持约15%）。片段末尾无A，边界不会制造额外AX。拒绝连续非目标超过24项的序列；不是固定周期出现。三档改变节奏与干扰比例，不在轮内改变。

事件仍记录index,response,rtMs,onsetMs；Plan新增cptConfig和gapMs，windowMs同时定义刺激可见与响应窗口。服务端冻结并复算所有条件；版本2.0与1.0隔离。比较键包含版本、玩法、实际时长、档位、模式与设备。

报告：目标命中hits/targets、遗漏、非目标误报falseAlarms/nonTargets；全程、前半、后半分别报告n、targets、misses、falseAlarms、无线索X误按/无线索X机会、A提前按/A机会、其他误按、正确RT中位数和样本标准差。少于5个正确RT不显示时间统计；显示实际分母，不生成注意力等级或诊断结论。90秒练习不用于推断长时间持续注意能力。规则练习时提示具体漏报/误报原因，正式训练只有已记录反馈。
