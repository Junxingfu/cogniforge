# 工程设计

## 目录

- frontend/src/App.vue：导航、任务库、记录、趋势与个人数据入口。
- frontend/src/Training.vue：训练运行状态、计时、按键与点击、质量中止及待同步缓存。
- frontend/src/analysis.ts：可比数据筛选，独立测试防止混入不同条件。
- backend/.../Tasks.java：任务配置生成和纯服务端评分。
- backend/.../SessionController.java：身份归属、提交、读取、导出基础接口、复盘与删除。
- SessionMapper + TrainingSession：MyBatis-Plus数据持久化。

## API

除生成本机凭证外，所有接口使用 `Authorization: Bearer <token>`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/v1/identity | 生成随机本机凭证，不收集个人信息 |
| POST | /api/v1/sessions | task、level、mode、device；返回id与冻结的plan |
| PUT | /api/v1/sessions/{id}/result | status、events、quality、reflection；重新评分并幂等保存 |
| GET | /api/v1/sessions | 当前凭证所属记录摘要 |
| GET | /api/v1/sessions/{id} | 原始配置与提交数据 |
| PATCH | /api/v1/sessions/{id}/reflection | 修改反思文字 |
| DELETE | /api/v1/sessions | 删除当前凭证所属全部记录 |

mode：PRACTICE、TRAINING、RETEST。status：RUNNING → COMPLETED / ABORTED，不允许反向迁移。

事件为 `{index,response,rtMs,onsetMs}`。时间单位毫秒，onsetMs为会话内单调时钟偏移；无响应时response为空串，rtMs为null。二元任务仅接受PRESS/空串。序列任务响应为逗号分隔的点击位置。Schulte含误点的试次算错误，即使最终找到了该数字；原始点击串保留用于后续细分统计。

训练会话使用随机UUID，服务器用归属哈希隔离记录；通过条件更新 RUNNING 状态实现提交竞争保护。相同请求重放返回同一结果，不同内容409。复盘修改不改原始试次提交。

## 同步与中断

每轮完成即更新localStorage待提交快照。正常完成提交COMPLETED；失焦/主动结束/明显超时提交ABORTED。刷新丢失运行状态时，可将已保存快照补传为ABORTED，不把不完整训练补成完成。

训练必须在线取得配置；开始后断网可以完成当前会话，提交失败显示待同步。不是完整离线应用：不支持离线新建会话。本地存储容量/禁用情况仍需进一步强化，部署前需完善可靠队列与错误监控。

## 版本边界

目前数据库只用一张会话表，配置、提交、结果以JSON文本保存，适合小规模开发。不是长期大规模分析架构：后续将逐试次拆表、增加归属时间索引、分页、结果版本和后台聚合。MySQL需数据库迁移工具管理升级。

当前匿名凭证保存在localStorage，不具备恢复和过期。后续正式账号应用Spring Security与HttpOnly会话，并迁移匿名记录。应用只绑定127.0.0.1，开发阶段不对外发布。
