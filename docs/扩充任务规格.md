# 扩充任务协议 1.0
所有任务复用规则练习/正式训练/固定复测、服务端冻结刺激、逐试次事件、离线重传、中断剔除和同条件趋势。三档参数固定，首版不声称自动测量能力或临床评估。

|任务|刺激与参数|响应与评分|
|---|---|---|
|Stroop|40项，红蓝绿黄各10项；每颜色5匹配5冲突；窗口2500/2000/1500ms|选墨水颜色，不选字义；两条件准确率、正确RT中位数；冲突减匹配中位数，任一条件少于5正确响应则不报告差值|
|任务切换|1个熟悉项+40项；大小/奇偶规则，20次切换20次重复；数字1–9排除5；窗口2500/2000/1500ms|大小规则：小于5左、大于5右；奇偶规则：奇左偶右。首项不评分；分别报告切换/重复准确率与RT及差值，少于5正确响应不算差值|
|CPT|120/180/240项，每60项恰6个X；响应1000ms+间隔500ms|只对X按空格或目标按钮；命中、虚报；每60项独立统计遗漏/误报和正确RT标准差；不是ADHD检测|
|数字正背/倒背|各5轮，每轮3/4/5/6个不重复数字（内部档位1/2/3/4，成绩按长度分组）；每数字800ms+空白200ms|隐藏后以原序/反序输入；15秒窗口；整序列正确率及完整输入时间，固定长度练习不是最大记忆广度测验|
|组块练习|3轮6/9/12位数字，每3位分组，编码15/20/25秒|隐藏后原序输入；60秒窗口；整组序列准确率，练习后填写真实清单应用复盘|
|位置记忆法|3轮4/6/8个常见词，固定熟悉路线位置标签；编码15/20/25秒|先想象每个词与对应位置互动；隐藏后按路线回忆输入，用空格分隔；60秒窗口；完整列表正确率，逐轮位置正确率。须理解中文词语；仅即时回忆，不能据此推断长期记忆改善|

数据沿用Plan(task,level,version,windowMs,stimuli,expected)，stimuli含可复算条件：Stroop为字义|墨色；切换为规则|数字。事件含index,response,rtMs,onsetMs。结果增加breakdown：各条件n/correct/accuracy/medianRt及目标、遗漏、误报、正确RT标准差。数字和词表还保存逐位置命中率。超时空响应以null RT保存；不可修改已提交试次。策略与反应时任务不横向排位。切走中断，部分数据保留但不入趋势。

## Stroop 1.1 操作更新
刺激改用深中性背景与明亮红蓝绿黄（黄色 #ffdf00）；答案固定红蓝绿黄顺序，每项同时提供色块和汉字，支持数字键1–4（含小键盘），保留第一响应并忽略长按。窗口与条件比例不变；与1.0隔离比较。输入方式可混用，当前未单独记录鼠标/键盘，应保持个人输入习惯一致解释速度变化。

## Stroop 1.2
按用户反馈撤除选项色块，答案统一中性色汉字红、蓝、绿、黄，保留1–4快捷键、明亮黄色和深中性刺激背景。1.0、1.1、1.2分别比较，避免规则变化混入趋势。
