# 首版任务规格与体验决策 v0.3

日期：2026-10-27。范围：普通成年人自主练习；优先清晰、可解释、可复盘，不增加教练体系。本文先约定产品行为，再据此实施。标注“当前”的内容与任务协议1.0一致；“下一协议”不得静默改变历史评分。

## 1. 用户旅程与本轮决策

用户需要依次知道：练什么 → 为什么练 → 具体怎么操作 → 选哪个参数 → 什么时候结束 → 哪类错误值得关注 → 下次怎么练。

- 今日是入口，训练库是选任务；页面切换必须回到顶部并转移内容焦点，当前导航有可访问状态。
- 点卡片先进入规则与参数页，不立即计时。即使服务暂不可用也能阅读规则，只有开始按钮依赖连接。
- 不再用跨任务的“入门/进阶/挑战”掩盖参数；n-back显示N值，Go/No-Go显示响应窗口，空间路径显示序列长度，舒尔特固定4×4。
- 模式明确展示：规则练习、正式训练、固定复测。现有练习模式只是数据分组，不得声称已提供短教程或掌握度认证。
- 结果页按任务给主要指标；命中与虚报必须一起看。空间序列不以点击速度作为主要成绩。
- 查看分析时的筛选不能改变下次训练的模式或难度。
- “返回训练库”必须真的返回训练库，而非回到进入任务前的首页下半部分。

## 2. 共用规则与数据含义

当前每个会话只有一个训练区块。规则练习不进入正式训练计数。复测固定配置，新序列不代表经过心理测量等值验证。仅将相同任务、版本、配置、模式、输入方式和可比设备条件的数据比较；当前代码只具备任务/档位/模式/设备筛选，版本和完整配置分组列入下一协议工作。

时间采用单调时钟；页面渲染后开启响应窗口。浏览器时间不是实验室级真实刺激呈现时刻。焦点丢失、用户结束、计时延迟必须保留状态，不用无效区块制造下降趋势。

当前通用评分：accuracy = correct / scoredTrials；分母为0返回null。中位反应时仅包含有响应且正确的试次；偶数样本取中间两项均值。结果必须显示样本量。无响应不从正确率分母删除。部分输入超时的rt目前记录截止窗口，不能解释为真实最后点击时间。

## 3. 更新挑战 / 单通道视觉 n-back

### 当前协议1.0

- 刺激：A–H八个大写字母；一项呈现2500ms，准备间隔500ms；只接受首次空格按下，忽略长按重复。
- 难度：N=1/2/3，其他参数固定。总项数30+N；前N项只编码，不评分。
- 目标：30个可评分项中恰好9项满足当前字符等于N步前字符；其余21项排除意外N步重复。目标位置随机，不保证连续目标上限。
- 用户说明举例：1-back的A→A，2-back的A→B→A，3-back的A→B→C→A；最后一项应按空格。符号相同但距离不符不按。
- 完成：全部项执行完毕，约93–99秒；中途离开记中断。

### 评分与解释

H=目标按键，M=目标未按，F=非目标按键，CR=非目标未按。
命中率=H/(H+M)，漏报率=M/(H+M)，虚报率=F/(F+CR)，正确率=(H+CR)/30。
全不按时正确率70%但命中率0%；全按时命中率100%但虚报率100%。两者都不能获得升级建议。前N项的按键保留但不参与评分。当前不提供d′，避免小样本极端比例未经校正。

结果优先：目标命中、非目标虚报、可评分样本数；正确响应中位时间为次级指标。提示围绕“漏看目标/过早作答”，不推断工作记忆缺陷。

## 4. 停走信号 / Go/No-Go

### 当前协议1.0

- 刺激：GO与STOP文字，不能仅靠颜色区分。
- 40项：Go 30项，No-Go 10项，随机打乱。不是Stop-signal任务，不计算停止信号反应时。
- 难度：响应窗口1000/850/700ms；刺激在窗口中可见；起始间隔固定1500ms，剩余时间显示准备符号。
- Go首次空格有效；No-Go不按。响应截止后按键不计当前项；当前实现不保留每次超窗按键，不能声称已记录所有物理输入。
- 全部完成约60秒。

### 评分与解释

Go命中率=Go正确按键数/30；Go漏报率=Go无响应数/30；No-Go误按率=No-Go按键数/10。
总体正确率=(Go命中+No-Go正确拒绝)/40；正确Go响应中位数单独显示。
全按的正确率75%、No-Go误按100%；全不按的正确率25%、Go命中0%。优先呈现Go命中与No-Go误按，不用总体正确率判定抑制能力。

只有10个No-Go样本，一次误按即10个百分点；显示错误次数，避免把单轮波动解释为趋势。增加样本应优先聚合同条件区块，不强迫一次练很久。

## 5. 空间路径 / Corsi启发的序列任务

### 当前协议1.0

- 固定3×3网格，9个位置（内部索引0–8）；这是产品化衍生任务，不是标准化Corsi测评。
- 每轮序列长度3/4/5，对应内部档位1/2/3；不重复抽取位置。每块5轮固定长度，不在块内自动升降。
- 各位置亮起550ms，间隔200ms；呈现时禁止输入。
- 呈现结束后15秒内按序点击；输入满长度即结束本轮；部分输入或未输入超时记错误，保留已输入内容。
- 用户可见时长是范围：约15秒至1分40秒，受输入时间影响，不能统一标为精确2分钟。

### 评分与解释

主要：整条序列完全正确的轮数/5，同长度成功率。最长一次成功的长度不是稳定空间记忆跨度。次级：正确序列完整输入时间中位数，明确不是单击反应时。

下一协议增加逐位置匹配数/位置总数、首个错误位置与每次点击时间。它们帮助定位顺序错误，但不替代整序列正确率。

## 6. 数字寻踪 / 舒尔特方格

### 当前协议1.0（如实保留）

- 4×4随机排列1–16，布局全程不变。从1开始，点错不推进，正确后寻找下一数字。
- 每个数字最多60秒；旧逻辑超时会跳到下一个目标。该行为并非理想产品规则，本轮不静默改变计分协议。
- 单个目标的response保存该目标下的点击串；仅一次正确点击才计此试次正确，有误点但最终找到也计错误。
- 当前展示无误目标数/16、正确目标查找耗时中位数。不能把16/16解释为高注意力，更不能将这两个指标包装成标准舒尔特总分。

### 下一协议1.1的产品要求（待实现）

- 每目标60秒无正确响应时结束为超时，不跳过数字；只有找齐16个才完成。
- 主要指标：从网格首次可见到最后正确点击的总耗时、误点总数、完成目标数；完整持续记录点击，无人为每目标准备间隔。
- 训练有效完成但有误点仍可显示完成用时，同时显示误点；不添加未经验证的“每错一次加3秒”惩罚。
- 首版仍固定4×4，5×5为未来独立配置；不能与4×4混合速度趋势。

## 8. 自适应与训练安排

本轮不启用自动升降级。后续候选规则：n-back至少两个有效区块，命中≥80%且虚报≤20%才考虑升一级；Go/No-Go至少聚合20个No-Go，再同时检查Go命中与No-Go误按；空间序列需同长度至少10轮。阈值仅为试点假设，不是临床标准。固定复测永不自适应，用户可锁定难度。

每日组合待规则验证后实施：可选热身 + 两项不同侧重任务 + 一条复盘；不把做满所有任务作为奖励条件。先看完成负担、教程理解、数据有效率，不把分数上升当成产品效果证明。

## 9. 实施顺序与验收

P0本轮：导航与滚动回归；正确返回训练库；任务参数具体化；操作示例；模式提示；任务特异结果；分析筛选不污染训练设置；后端不可用时明确反馈。

P1下一协议：先补服务端配置/评分版本与事件契约测试，再实现短练习反馈、舒尔特超时和总用时、逐点击采集、质量事件数组。迁移时区分1.0/1.1数据。

P2：跨区块自适应、每日组合、完整记忆宫殿、正式账号和跨设备恢复。各项都需先完成可复现验收，不能同时扩展任务数量掩盖基础体验问题。

验收样例：滚动720px后切换页面应回到0；重复点击当前导航也回顶部；从首页打开任务后返回到训练库；1-back与3-back有不同示例与时长；分析中改模式不改变训练模式；n-back全不按显示命中0%而不是“表现良好”；Go全按显示No-Go误按100%；服务断开仍可读规则但不能开始。
